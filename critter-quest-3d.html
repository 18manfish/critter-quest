🐾 Critter Quest

Arrows/WASD or d-pad. Press M or Esc for the menu. Talk to the white dot (Professor) first. C heals, M is the Mart, G is a gym. Tall grass has wild critters; on sea routes you sail, and critters live in the water.


  

    Add a new critter or item

defineMove('Moonbeam', 'Normal', 70, 95);
defineSpecies({ id: 'lunari', name: 'Lunari', type: 'Air', base: [50, 55, 50, 70], evo: [20, 'lunaros'] });
// then add 'lunari' to a route's species list in ROUTES, or to a gym team.
// New route: add { name, from, to, level, species, path, sea? } to ROUTES. Town maps get the new exit automatically.
// New item: add an entry to ITEMS (heal / revive / ball) and to MART_STOCK.


TILED MAPS: export from Tiled as JSON (Tile Layer Format: CSV, tilesets embedded).
- Map id = file name or map property "area": 0..16 (even = town, odd = route), g1 / g2 = gym of town 1 / 2.
  The nine towns ship built in (towns/town-<area>.json, prussian-tiles); a loaded map replaces the built-in one.
  Routes, side areas and gym interiors are generated, drawn with the same tile set. Big maps scroll with the player.
- Tileset tiles get a custom string property "kind": ground tree grass path water center gym building wall exit mart.
  tree/water/building/wall block movement, grass triggers wild battles, center/mart/gym are doors, exit leaves a gym.
  Tiles without "kind" are decoration. Use an invisible layer of kind tiles for collisions if you like.
- Object layer classes: prof | leader (property town) | spawn (point) | warp (rectangle; props to, tx, ty)
  | npc (property dialogue = id in DIALOGUES) | trigger (rectangle; props dialogue, on = step/areaEnter, once, flag).
  Open cells on a map edge lead along the world routes (the edge = the route's direction on the world map).
  Map property sea = true makes water walkable by boat (on by default for sea routes).
- Map properties: name (label), floor (background colour).
- Use the Load button to pick map JSON + tileset PNG files together (external .tsj tilesets work too),
  or paste JSON: TILED_MAPS['0'] = {...}; images: TILESET_IMAGES['tiles.png'] = Object.assign(new Image(), {src: 'data:...'}).
